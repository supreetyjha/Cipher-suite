# Caesar Cipher Encoder/Decoder

A Python-based command-line tool to encrypt and decrypt messages using the classic Caesar Cipher technique.

## 🚀 Features
* **Encryption/Decryption:** Shift messages by any key (1-25).
* **Special Character Support:** Keeps spaces and punctuation intact.
* **Brute-Force Mode:** Automatically attempts all 26 shifts to crack a code.
* **Frequency Analysis:** Displays letter counts to show how substitution ciphers work.

## 🛠️ How to Use
1. Clone the repo: `git clone https://github.com/YourUsername/your-repo-name.git`
2. Run the script: `python main.py`
3. Follow the CLI prompts to encrypt or decrypt.

## 📈 Learning Outcomes
This project was built to explore string manipulation, the modulo operator, and basic cryptographic vulnerabilities.
